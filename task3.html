``` ## Explanation ### 1. Sidebar Layout ```css .container { display: flex; } ``` This places the **sidebar and main content side-by-side**. ```css .sidebar { width: 200px; } ``` This gives the sidebar a fixed width. --- ### 2. CSS Box Model The product card uses: ```css .product-card { margin: 20px; padding: 20px; border: 2px solid #333; } ``` The CSS box model consists of: **Content → Padding → Border → Margin** * **Content** → Product information * **Padding** → Space inside the card * **Border** → Line around the card * **Margin** → Space outside the card --- ### 3. 3-Column Blog Layout ```css .blog-container { display: flex; gap: 20px; } ``` Flexbox places the three blogs in one row. ```css .blog { flex: 1; } ``` `flex: 1` gives each blog approximately equal width. --- ### 4. Media Query ```css @media screen and (max-width: 600px) { ``` This CSS runs when the screen width is **600px or less**, such as on a mobile phone. The sidebar moves to the top: ```css .container { flex-direction: column; } ``` And the three blogs become one column: ```css .blog-container { flex-direction: column; } ``` ## Result ### Desktop ```text ----------------------------------- My Responsive Website ----------------------------------- | Sidebar | Product Card | | | | | Home | Latest Blogs | | Product | --------------------- | | Blog | Blog 1 | Blog 2 | Blog 3 | Contact | --------------------- | ----------------------------------- ``` ### Mobile ```text ---------------------- My Responsive Website ---------------------- Menu Home Products Blog Contact ---------------------- Product Card ------------------- | Smart Watch | ------------------- ---------------------- Blog 1 ---------------------- Blog 2 ---------------------- Blog 3 ---------------------- ```
